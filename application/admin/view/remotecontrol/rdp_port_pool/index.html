端口池状态由映射记录自动判断：已分配的端口不会重复分配，未分配端口自动参与分配。公网访问状态来自宿主机端口管理服务，开放或关闭操作实时生效。
{:__('Refresh')} 开放选中端口 关闭选中端口
字段和值说明
项目 可能的值 说明
端口6011-6999FRPS 对公网提供的 TCP 端口；已分配端口不会重复分配。
端口池状态已分配 / 未分配“已分配”表示数据库中已有用户设备映射；“未分配”表示没有映射，会自动参与后续分配。
代理状态空闲数据库没有映射，FRPS 中也没有检测到在线代理。
代理状态RustDesk在线端口已分配，且 FRPS 中的在线代理名称与预期代理名一致。
代理状态已分配未上线数据库已经分配端口，但 FRPS 中暂未检测到对应在线代理；可能是 frpc 未启动、掉线或正在启动。
代理状态已分配/未核验端口已分配，但 FRPS Dashboard 当前不可用，无法核验代理是否在线。
代理状态未知占用数据库没有分配记录，但 FRPS 中存在其他在线代理，该端口不能视为安全空闲。
代理状态映射冲突数据库已分配端口，但 FRPS 实际代理名与预期代理名不一致。
代理状态监控不可用FRPS Dashboard 未配置、认证失败或连接失败，且端口没有数据库映射。
公网访问状态开放 / 关闭 / 未知“开放”表示 port-manager 已允许该 TCP 端口；“关闭”表示已拦截；“未知”表示端口管理接口配置错误、连接失败或返回异常。
用户 ID / 设备 ID数字 / RustDesk设备标识显示当前获得该端口的用户和设备；未分配时为空。
后台状态pending / allocated / active / stopping / inactive依次表示等待分配确认、已分配、运行中、等待客户端 FRPC 断开、已停止；不会停止共享 FRPS 服务。
预期代理名rustdesk-rdp-u...-d...后端生成并要求客户端启动 frpc 时使用的代理名称。
FRPS 实际代理名FRPS返回的代理名称从 FRPS Dashboard 实时读取，用于和预期代理名核对。
FRPS 状态online / offline / 空FRPS 返回的原始代理运行状态；空表示未查询到代理。
监控说明空或错误信息正常时为空；FRPS Dashboard 读取失败时显示具体原因。
公网访问说明空或错误信息正常时为空；port-manager 查询失败时显示具体原因。
公网访问操作开放 / 关闭调用宿主机 port-manager 修改 TCP 端口访问规则，成功后立即刷新列表。
